# GLM Bourse 🤖📈

سیستم ۴ ایجنته امتیازدهی بورس ایران — کاملاً محلی، deterministic و بدون API خارجی.

هر نماد بورس توسط زنجیره‌ای از ۴ ایجنت تحلیل می‌شود و خروجی، **امتیاز ۱ تا ۱۰۰** و
سیگنال **خرید / فروش / نگهداری / نظاره** روی یک وب‌پیج فارسی RTL است.

## زنجیره ایجنت‌ها

| # | ایجنت | وظیفه |
|---|-------|-------|
| ۱ | **Collector** (جمع‌آوری اطلاعات) | دریافت دیتای زنده از TSETMC (کندل‌های روزانه + حقیقی/حقوقی)، اعتبارسنجی تازگی داده، رد نمادهای متوقف |
| ۲ | **Processor** (پردازش اطلاعات) | محاسبه EMA20/50/200، ایچیموکو، RSI، MACD، ATR، فیبوناچی، حجم نسبی، جریان پول حقیقی → امتیاز ۰-۱۰۰ برای هر پارامتر |
| ۳ | **Tactician** (نقاط تاکتیکی) | محدوده ورود (پول‌بک به EMA20/فیبو ۰٫۳۸۲-۰٫۵)، حد ضرر (کیجون/سوینگ−ATR با سقف ۱۲٪)، هدف ۱ و ۲، نسبت بازده/ریسک، اندازه موقعیت |
| ۴ | **Announcer** (اعلام نتیجه) | امتیاز وزنی کل → سیگنال نهایی بر اساس آستانه‌های config + دلایل مثبت/ریسک‌ها |

## امتیازدهی وزنی

هر پارامتر تکنیکال یک **وزن** دارد (قابل تغییر از UI با اسلایدر) و امتیاز کل =
Σ(امتیاز پارامتر × وزن). اگر پارامتری در دسترس نباشد، وزنش بین بقیه بازتوزیع می‌شود.

| پارامتر | وزن پیش‌فرض |
|---------|-------------|
| روند (EMA20/50/200) | ۲۰٪ |
| ایچیموکو | ۱۵٪ |
| RSI | ۱۵٪ |
| MACD | ۱۵٪ |
| حجم و نقدشوندگی | ۱۰٪ |
| حقیقی/حقوقی (جریان پول) | ۱۵٪ |
| موقعیت قیمت (فیبوناچی) | ۱۰٪ |

آستانه‌های سیگنال (قابل تنظیم): امتیاز ≥۷۰ خرید · ≥۵۵ نگهداری · ≥۴۰ نظاره · کمتر = فروش

## اجرا

```bash
pip install -r requirements.txt
python app.py
```

سپس مرورگر: **http://127.0.0.1:5001**

## امکانات

- **واچ‌لیست** — افزودن/حذف نمادهای موردنظر با یادداشت؛ دکمه «بررسی همه» هر نماد را با ۴ ایجنت
  تحلیل می‌کند، سیگنال هر نماد را در جدول نشان می‌دهد و اگر سیگنال نسبت به تحلیل قبلی
  عوض شده باشد هشدار «تغییر از ...» می‌دهد
- تحلیل چند نماد هم‌زمان (با کاما جدا کنید، حداکثر ۲۰)
- گیج حلقه‌ای امتیاز + نوار امتیاز هر پارامتر با دلیل فارسی
- کارت نقاط تاکتیکی: ورود، حد ضرر، اهداف، نسبت ریسک/بازده، حجم مجاز موقعیت
  (اگر R/R زیر ۲ باشد حجم صفر پیشنهاد می‌شود تا در پول‌بک شکار شود)
- پنل اسلایدر وزن‌ها + آستانه‌ها → ذخیره در `config.json`
- تاریخچه تحلیل‌ها در SQLite با امکان حذف
- واچ‌لیست در جدول SQLite (`watchlist`) ذخیره می‌شود

## نکات فنی

- از **API جدید SPA** سایت TSETMC استفاده می‌کند (`cdn.tsetmc.com/api/...`) — endpointهای قدیمی
  (Loader.aspx) مرده‌اند.
- `trust_env=False` روی session ست شده تا پروکسی سیستم ویندوز (فیلترشکن‌ها) نتیجه را خراب نکند.
  در صورت نیاز، متغیر محیطی `TSE_PROXY` را تنظیم کنید (`none` = فقط مستقیم).
- TSETMC بدون User-Agent مرورگر پاسخ 403 می‌دهد — کلاینت هدر مناسب می‌فرستد.

## ⚠️ سلب مسئولیت

این ابزار فقط برای **تحلیل و آموزش** است؛ سیگنال خرید/فروش نیست. مسئولیت هر
معامله با خود کاربر است. با پولی که تحمل از دست دادنش را ندارید معامله نکنید.
